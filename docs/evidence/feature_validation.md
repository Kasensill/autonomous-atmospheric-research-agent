# 功能线评测与验收索引

本页按功能线汇总历史观察与未验证项。更新时追加日期、代码版本、测试条件和结果，保留失败记录。原始 Trace、模型调用和逐轮报告存放于被 Git 忽略的 `docs/validation/<日期>/`；其他克隆环境不一定有这些本地文件。这里记录摘要，不把历史成绩当成当前版本的保证。

两组重构问题使用“刚才那条回答”，并非旧报告中的逐字题目。其他指代表述、主题歧义、窗口外目标和模型多次重复稳定性未在该复验覆盖。当前主题匹配是归一化连续子串，存在“北京暴雨”不匹配“北京特大暴雨”的已知限制。开放验证见[改进清单](../architecture/improvement_backlog.md#2026-11-05-开放问题和验证缺口)。
