## 不立即实施的通用建议

- Markdown 知识库没有天然页码；只有接入 PDF 时才引入 `page` 元数据。
- 当前约 200 个 Chunk 的规模下，BM25 每次由持久化 token 索引重建的成本可接受；规模增长后再考虑
  常驻索引或专用搜索服务。
- Evidence Review 与 Report Verification 当前应保持分离：前者判断证据覆盖，后者判断报告是否忠于证据；
  不为减少一次模型调用而牺牲职责边界。
